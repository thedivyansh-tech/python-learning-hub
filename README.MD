# 🐍 Python Learning Hub

Welcome to my Python learning repository! This is a collection of beginner-friendly Python scripts, exercises, and mini-projects designed to help anyone learn programming from scratch.

---

## 📂 Repository Structure

- **`01-basics/`** — Learn variables, data types, string formatting, and user inputs.
- **`02-control-flow/`** — Master `if/else` statements, `for` loops, and `while` loops.
- **`03-functions/`** — Understand how to write clean, reusable code blocks.
- **`projects/`** — Full, interactive mini-projects bringing multiple concepts together.
